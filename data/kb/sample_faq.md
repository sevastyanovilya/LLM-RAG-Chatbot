# LLM RAG Chatbot - FAQ проекта

## Что это за проект?

Это production-ready RAG (Retrieval-Augmented Generation) чатбот, демонстрирующий best practices ML-инженерии. Система использует векторный поиск для извлечения релевантного контекста из базы знаний и генерирует ответы, используя либо локальную LLM (qwen2.5-7b-instruct), либо hosted API (GPT-4o-mini).

## Какие технологии используются?

Проект использует:
- Python 3.11 для runtime
- FastAPI для веб API
- FAISS для векторного поиска (CPU-оптимизирован)
- Sentence transformers для embeddings
- llama.cpp для локального LLM inference
- pytest для тестирования
- Docker для контейнеризации
- GitHub Actions для CI/CD

## Как запустить локально?

Сначала склонируйте репозиторий и выполните `make setup` для установки зависимостей. Затем запустите `make ingest` для построения векторного индекса из документов в `data/kb/`. Наконец, запустите сервер командой `make run` и он будет доступен на http://localhost:8000.

## Каковы системные требования?

Система спроектирована для работы на CPU-only машинах. Минимальные требования: 4GB RAM (рекомендуется 8GB) и минимум 5GB дискового пространства для моделей и зависимостей. Рекомендуется современный многоядерный CPU для приемлемого времени отклика.

## Могу ли я использовать свои документы?

Да! Поместите ваши Markdown, PDF или текстовые файлы в директорию `data/kb/` и выполните `make ingest` для пересборки индекса. Система автоматически разобьет на чанки и создаст embeddings ваших документов.

## Насколько точен retrieval?

На нашем evaluation наборе система достигает >75% точности retrieval (нахождение релевантного контекста) и >60% семантического совпадения с эталонными ответами. Производительность варьируется в зависимости от качества документов и сложности запросов.
